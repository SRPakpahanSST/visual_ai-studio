# 🎨 VisualAI Studio

**VisualAI Studio** adalah aplikasi berbasis Generative AI untuk membuat dan mengedit gambar secara instan. Dibangun dengan Streamlit dan Stable Diffusion, aplikasi ini dirancang untuk membantu UMKM, profesional, dan pelajar dalam menciptakan konten visual berkualitas tinggi tanpa keahlian desain.

## ✨ Fitur
- **Text-to-Image**: Ubah teks menjadi gambar dengan gaya 2D digital art.
- **Inpainting**: Tambah atau ubah objek dalam gambar (contoh: broken satellite).
- **Outpainting**: Perluas gambar ke segala arah dengan konten konsisten.
- **Batch Generation**: Hasilkan 4 gambar sekaligus dalam grid 2x2.
- **Parameter Customization**: Atur guidance scale, inference steps, dan scheduler.
